# dsh-life-pipline

`dsh-lpipe-` 系列的公共包：在 **设置** 侧栏提供一页「Lpipe 设置」，每个已安装的组件把自己的那块设置注册进去。

它提供这一页容器与所有组件共用的「公共」设置（主会话）：

- 侧栏始终只有一条「Lpipe 设置」，装几个组件都不会变多。
- 组件通过依赖它来获得这一页，所以安装任意一个 `dsh-lpipe-*` 组件时，它作为依赖被一起装上。

## 安装

**安装任何 `dsh-lpipe-` 组件之前，必须先安装本包。** 本包负责注册设置里的「Lpipe 设置」页面与公共部分；组件只负责往那一页里添加自己的配置项。没装本包就只会得到一堆没有设置入口的组件。

顺序：先安装 **Life Pipline**（本包），再安装你要的组件，例如 `dsh-lpipe-chat`。

## 组件

| 组件 | 包 | 说明 |
| --- | --- | --- |
| Lpipe Chat | `dsh-lpipe-chat` | 自己持有微信与 QQ 通道：扫码接入、合并连发消息、注入主会话 |
| Lpipe Wake | `dsh-lpipe-wake` | 停下一段时间后，在主会话里把自己叫醒；设置页可一键关掉 |

## 许可

AGPL-3.0-or-later。第三方代码的许可见 `dsh-lpipe-chat` 包内的 `THIRD_PARTY/`。
