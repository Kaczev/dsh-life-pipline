# dsh-life-pipline · 生命管线

生命管线是整套插件的聚合安装入口。安装本包会带上生命核心和七条管线，并通过宿主插件管理服务启用各自的 bundle。

- `dsh-life-core`：共享设置、主会话、工作区、隔离规则和共用模块。
- `dsh-lpipe-chat`：微信与 QQ 聊天。
- `dsh-lpipe-home`：模型的个人文件夹。
- `dsh-lpipe-bili`：B 站浏览、字幕和隔离分镜。
- `dsh-lpipe-wake`：自然唤醒与自主安排的唤醒。
- `dsh-lpipe-memory`：会话原文存储。
- `dsh-lpipe-starmap`：从记忆抽取星图。
- `dsh-lpipe-recall`：根据星图与记忆提供回忆。

## 安装与开关

可以安装 `dsh-life-pipline` 获得整套，也可以只安装需要的 `dsh-lpipe-*`。单独安装管线会带上核心；星图还需要记忆，回忆还需要星图和记忆。

每个组件使用自己的规范挂载行，整套与单独安装混用时不会重复插入插件行。组件开关通过宿主插件管理服务联动：开启回忆补齐前置，关闭记忆连带关闭星图和回忆。再次开启前置组件不会自动恢复用户已关闭的下游组件。

聚合入口的详情页提供核心与七条管线的统一开关，实际操作各自的规范挂载行，不复制插件实例。独立 bundle 仍由宿主管理并可单独开关。关闭聚合入口不会删除已选择的独立 bundle；需要停用某条管线时，使用该管线的开关。

## 兼容

共享设置移到 `dsh-life-core`，原来的数据目录、主会话绑定、工作区选择和渠道凭据保持不变。设置页仍是「Lpipe 设置」。

## 许可

AGPL-3.0-or-later。各业务组件与内置第三方代码遵循各自包内的许可说明。
