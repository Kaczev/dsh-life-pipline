# dsh-life-pipline

`dsh-lpipe-` 系列的公共包：在 **设置** 侧栏提供一页「Lpipe 设置」，每个已安装的组件把自己的那块设置注册进去。

它提供这一页容器与所有组件共用的「公共」设置（主会话）：

- 侧栏始终只有一条「Lpipe 设置」，装几个组件都不会变多。
- 组件通过依赖它来获得这一页，所以安装任意一个 `dsh-lpipe-*` 组件时，它作为依赖被一起装上。
- 会话栏里主会话标题左侧那枚小气泡标记也归本包：主会话是共用状态，不该由某个组件占着这个座位。

## 安装

**安装任何 `dsh-lpipe-` 组件之前，必须先安装本包。** 本包负责注册设置里的「Lpipe 设置」页面与公共部分；组件只负责往那一页里添加自己的配置项。没装本包就只会得到一堆没有设置入口的组件。

顺序：先安装 **Life Pipline**（本包），再安装你要的组件，例如 `dsh-lpipe-chat`。

## 组件

| 组件 | 包 | 说明 |
| --- | --- | --- |
| Lpipe Chat | `dsh-lpipe-chat` | 自己持有微信与 QQ 通道：扫码接入、合并连发消息、注入主会话；注入带微信式时间分隔，图片随消息一起进来 |
| Lpipe Wake | `dsh-lpipe-wake` | 停下一段时间后把自己叫醒（跨天说清是哪天）；也能自己约时刻、带上缘由。自然 / 主动各一个开关 |
| Lpipe Memory | `dsh-lpipe-memory` | 把对话原文逐字留住：一个对话一个文件夹、按天分卷、哈希链可校验；按 `seq` 只解一帧读回 |

通知触发的轮次里不问选择题：微信 / QQ 批次与唤醒通知都可能在主人离开电脑时到达，而 `ask_user_question` 的选项只能在宿主界面里点，问出去会把这一轮挂住。两件事一起兜住它——chat 与 wake 各往系统提示词里写一条英文规则，本包还会在 `tools/pre-execute` 直接拒绝该工具，并用英文说明理由。

`chat_send` 另有选填的 `completed`（默认 false）：置 true 时这一轮当场结束，不再多花一次请求在宿主里复述同一句话。

## 许可

AGPL-3.0-or-later。第三方代码的许可见 `dsh-lpipe-chat` 包内的 `THIRD_PARTY/`。
