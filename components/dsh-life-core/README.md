# dsh-life-core · 生命核心

生命核心提供「Lpipe 设置」页面、主会话绑定与创建、工作区选择、会话标记、主会话工具隔离，以及共用时钟和活动读取。

每条 `dsh-lpipe-*` 管线都依赖本包。单独安装管线后，管线通过宿主插件管理服务选择核心及必要的前置 bundle；安装 `dsh-life-pipline` 则选择整套管线。核心不依赖业务组件。

开启回忆会补齐核心、记忆和星图。关闭记忆会连带关闭回忆、星图；再次开启记忆不会擅自恢复已关闭的下游管线。关闭核心会关闭所有依赖管线。联动使用宿主持久化开关，不修改 profile 文件，也不轮询覆盖用户选择。

配置仍保存在原来的 `life-pipline/config.json`。主会话绑定、工作区、业务数据和渠道凭据不迁移、不清空。公共 RPC 仍使用 `dsh-life-pipline`，设置槽仍为 `lpipe.settings.panel`。
