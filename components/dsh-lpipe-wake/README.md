# Lpipe Wake

停下一段时间之后，在主会话里把自己叫醒。生命管线的第二个组件。

## 它做什么

- 你开始活动时，下次唤醒被清空。
- 你停下之后，从停下的那一刻起算默认间隔（默认 2 小时），到点就往主会话注入一条消息。
- 宿主关着错过了也不补——重启后只要 `现在 >= 下次唤醒`，立刻触发一次，之后重新按默认间隔推算。
- 设置页有总开关，关掉之后完全不推算、不触发。

## 安装

本组件依赖 `dsh-life-pipline`（「Lpipe 设置」那一页由它注册），所以先装公共包：

```bash
npm i -g dsh-life-pipline
npm i -g dsh-lpipe-wake
```

或者在本仓库里：

```bash
node scripts/install-local.mjs
```

装完重启宿主，两个包都会出现在插件列表里；没自动启用的手动打上勾。

## 设置

宿主「设置 → Lpipe 设置」里，「公共」下面是主会话（所有组件共用），再下面是本组件的一块：

| 项 | 说明 |
| --- | --- |
| 开关 | 关掉就不再自行醒来 |
| 下次唤醒 | 当前的截止时间与倒计时 |
| 上次结束行动 | 你最后一次停下的时刻 |
| 默认唤醒间隔 | 30 分钟 / 1 小时 / 2 小时 / 4 小时 |
| 现在唤醒一次 | 立刻注入一条，随后重新推算 |
| 改回默认推算 | 丢掉手动设定，按「停下 + 间隔」重算 |

## 工具

`wake_set` 可以自己排下一次醒来：

```json
{ "in": "45m" }            // 45 分钟后
{ "at": "2026-11-05T08:00:00+08:00" }
{ "clear": true }          // 回到默认推算
{}                         // 只读，看看现在排在什么时候
```

多久都可以，触发条件只有一个：现在的时间戳到了设定的时间戳。

## 文件

| 路径 | 内容 |
| --- | --- |
| `~/.dsh/life-wake/state.json` | 开关、间隔、三个时间戳 |
| `~/.dsh/life-pipline/config.json` | 主会话 id（与其它组件共用） |
