# Lpipe Wake

停下一段时间之后，在主会话里把自己叫醒；也可以自己约一个时刻，带着一句写给那一刻的缘由。生命管线的第二个组件。

## 它做什么

两种唤醒，彼此独立，各有一个开关。

- **自然唤醒**：我停下之后，从「上次结束对话」起算默认间隔（默认 2 小时），到点往主会话注入一条。我一活动，这次的截止时间立刻往前推，所以不存在「到点但我还在活动」。
- **主动唤醒**：我自己用 `wake_set` 约的时刻，带一句缘由（比如悄悄准备一个惊喜）。它挂在独立的列表里，**我活动也不会取消它**。
- 宿主关着错过了也不补发一堆——重启后只要 `现在 >= 时刻`，立刻触发一次，然后重新推算。
- 引擎每 30 秒看一次（可调），到点误差不超过一次心跳。
- **只比时间戳**：每次心跳取一次「现在」，和截止时间比 `现在 >= 截止`；不靠倒计时累加，所以掉帧、休眠、慢机器都不会让唤醒偏移。
- **定时锁**：`wake_set { lock: "3h" }`（或给一个时刻）可以让自然唤醒在指定时间前不触发，到点自动恢复——相当于我自己临时关掉自然唤醒开关，但不用惊动开关本身。

## 安装

本组件依赖 `dsh-life-pipline`（「Lpipe 设置」那一页由它注册），所以先装公共包：

```bash
npm i -g dsh-life-pipline
npm i -g dsh-lpipe-wake
```

或者在本仓库里：

```bash
node scripts/install-local.mjs
```

装完重启宿主，两个包都会出现在插件列表里；没自动启用的手动打上勾。

## 设置

宿主「设置 → Lpipe 设置」里，「公共」下面是主会话（所有组件共用），再下面是本组件的一块：

| 项 | 说明 |
| --- | --- |
| 自然唤醒开关 | 关掉就不再按「停下 + 间隔」醒来；时间照样推算并显示 |
| 解锁 / 锁 2 小时 | 临时压住自然唤醒（按钮给 2 小时；`wake_set` 可给任意时长或时刻），锁着的时段在卡片上写明到几点 |
| 主动唤醒开关 | 关掉就到点也不醒；安排的列表原样留着 |
| 下次唤醒（自然） | 按「上次结束行动 + 间隔」算出的时刻与倒计时 |
| 上次结束行动 | 你最后一次停下的时刻，以及过去了多久 |
| 主动唤醒 | 最近的安排：时刻、倒计时、我写的缘由；多于一个时显示「另有 N 个」 |
| 现在醒来一次 | 立刻排一个主动唤醒（就在此刻） |
| 取消 / 全部取消 | 去掉最近一个安排，或者清空 |
| 默认唤醒间隔 | 自己填数字和单位，范围 1 分钟到 24 小时 |
| 心跳间隔 | 引擎多久看一次世界，默认 30 秒，可调 1 秒到 60 分钟；下面那条细线是这一次心跳已经走了多少 |

## 工具

`wake_set` 是排主动唤醒的：

```json
{ "in": "45m", "reason": "提醒他吃晚上的药" }   // 45 分钟后，带着这句缘由
{ "at": "2026-11-05T20:30:00+08:00", "reason": "偷偷准备的东西放好了" }
{ "cancel": true }        // 全部取消
{ "cancel": "<id>" }      // 只取消那一个
```

`wake_check` 是只读的，回答两个问题：

```json
{ "summary": "主动唤醒：2026-11-05 20:30，缘由：提醒他吃晚上的药。\n自然唤醒：2026-11-05 15:09，即上次结束行动 + 120 分钟。" }
```

时长与时刻都随意，触发条件只有一条：现在的时间戳到了那个时间戳。缘由会原样出现在醒来的那句话里。

## 文件

| 路径 | 内容 |
| --- | --- |
| `~/.dsh/life-wake/state.json` | 开关、锁到什么时候、默认间隔、心跳间隔、截止时间、几个时间戳 |
| `~/.dsh/life-pipline/config.json` | 主会话 id（与其它组件共用） |
