# Lpipe Wake

停下一段时间之后，在主会话里把自己叫醒。生命管线的第二个组件。

## 它做什么

- 你开始活动时，下次唤醒被清空。
- 你停下之后，从停下的那一刻起算默认间隔（默认 2 小时），到点就往主会话注入一条消息。
- 宿主关着错过了也不补——重启后只要 `现在 >= 下次唤醒`，立刻触发一次，之后重新按默认间隔推算。
- 设置页有总开关，关掉之后不触发（截止时间仍然推算并显示）。
- 唤醒分两种：**自然**唤醒按「结束 + 间隔」算；**主动**唤醒是我自己用 `wake_set` 定的时刻，一旦有更新的活动就作废，回到自然推算。
- 引擎每 30 秒看一次（可调），所以到点误差不超过一次心跳。

## 安装

本组件依赖 `dsh-life-pipline`（「Lpipe 设置」那一页由它注册），所以先装公共包：

```bash
npm i -g dsh-life-pipline
npm i -g dsh-lpipe-wake
```

或者在本仓库里：

```bash
node scripts/install-local.mjs
```

装完重启宿主，两个包都会出现在插件列表里；没自动启用的手动打上勾。

## 设置

宿主「设置 → Lpipe 设置」里，「公共」下面是主会话（所有组件共用），再下面是本组件的一块：

| 项 | 说明 |
| --- | --- |
| 开关 | 关掉就不再自行醒来（时间照样推算，只是不触发） |
| 下次唤醒 | 当前的截止时间与倒计时，后面标着它是哪一种：`自然` = 按「结束 + 间隔」算出来的，`主动` = 我自己设的时刻 |
| 上次结束行动 | 你最后一次停下的时刻，以及过去了多久 |
| 默认唤醒间隔 | 自己填数字和单位，范围 1 分钟到 24 小时 |
| 心跳间隔 | 引擎多久看一次世界，默认 30 秒，可调 1 秒到 60 分钟；下面那条细线是这一次心跳已经走了多少 |
| 现在唤醒一次 | 立刻注入一条，随后重新推算 |
| 改回默认推算 | 丢掉手动设定，按「停下 + 间隔」重算 |

## 工具

`wake_set` 可以自己排下一次醒来：

```json
{ "in": "45m" }            // 45 分钟后
{ "at": "2026-11-05T08:00:00+08:00" }
{ "clear": true }          // 回到默认推算
{}                         // 只读，看看现在排在什么时候
```

多久都可以，触发条件只有一个：现在的时间戳到了设定的时间戳。

## 文件

| 路径 | 内容 |
| --- | --- |
| `~/.dsh/life-wake/state.json` | 开关、默认间隔、心跳间隔、截止时间及其来源、几个时间戳 |
| `~/.dsh/life-pipline/config.json` | 主会话 id（与其它组件共用） |
