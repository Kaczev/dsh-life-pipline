# Kaomoji and Unicode emoji

Write kaomoji and Unicode emoji directly in `chat_send.text`. They are ordinary text and need no media upload or special message type.

Choose an expression that fits the conversation. A short reply usually needs only one; leave technical explanations readable and let serious messages stand without decoration. Follow the recipient's tone rather than adding an expression to every sentence.

A small palette to adapt, not a fixed rotation. These labels suggest conversational uses, not universal meanings:

| Tone | Kaomoji | Unicode emoji |
| --- | --- | --- |
| Gentle happiness | (˶ᵔ ᵕ ᵔ˶) | 😊 |
| Excitement | (≧▽≦) | 😄 🎉 |
| A hug or comfort | (づ｡◕‿‿◕｡)づ | 🤗 🫂 |
| Affection | (づ￣ ³￣)づ | ❤️ 🥰 |
| Shyness | (*ﾉωﾉ) | ☺️ |
| Playful teasing | (｡•̀ᴗ-)✧ | 😉 |
| Encouragement | (๑˃̵ᴗ˂̵)و | 💪 ✨ |
| Thinking or uncertainty | (・ω・) | 🤔 |
| Feeling hurt or sad | (｡•́︿•̀｡) | 🥺 😢 |
| Agreement or thanks | (•‿•) | 👍 🙏 |

Kaomoji depend on character spacing; keep each face together on one line. Emoji artwork varies by client and font. Describe these as text expressions or Unicode emoji when the distinction matters. If a recipient sees missing glyphs, use a simpler face such as `(^_^)` or an older emoji such as `😊`.

Selection references: [ToolNeko kaomoji collection](https://toolneko.com/zh-cn/tools/kaomoji/) and [Unicode emoji chart](https://unicode.org/emoji/charts/emoji-list.html). The selection is intentionally small; no need to load either full catalog to compose a reply.
